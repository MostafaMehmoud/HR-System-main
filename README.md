<p align="left"># 🖥️ HR Management System – Frontend (Angular)  <br><br>This is the **frontend application** for the HR Management System, built with **Angular** and connected to the .NET 9 backend API.  <br>It provides a **responsive, multilingual (Arabic/English)** interface that allows HR staff, managers, and employees to manage daily operations such as employee records, departments, attendance, payroll, and reporting.  <br><br>---<br><br>## 📌 Features<br>- 📋 **Employee Management** – Add, edit, and view employees.  <br>- 🏢 **Department & Job Titles** – Manage company hierarchy and job structures.  <br>- ⏱️ **Attendance & Leave** – Request and track attendance/leave.  <br>- 💰 **Payroll UI** – View salary, deductions, and generate reports.  <br>- 📊 **Reports** – User-friendly tables with filtering, sorting, and pagination.  <br>- 🌍 **Multilingual Support** – Arabic & English via Angular i18n.  <br>- 🔐 **Authentication & Authorization** – Login, role-based permissions, JWT token handling.  <br>- 🎨 **UI/UX Enhancements** – Bootstrap 5, SweetAlert dialogs, responsive design.  <br><br>---<br><br>## 🛠️ Tech Stack<br>- **Frontend Framework:** Angular (v16+)  <br>- **Languages:** TypeScript, HTML, CSS  <br>- **UI:** Bootstrap 5, SweetAlert, DataTables  <br>- **API Integration:** RESTful API (.NET 9 backend) with JWT Authentication  <br>- **Multilingual:** Angular i18n (Arabic/English)  <br><br>---<br><br>## 🚀 Getting Started<br>1.
